These examples follow API 1.0.0 and use synthetic values. Set `AMLOK_API_BASE_URL=https://api.amlok.io` and load a workspace key on your server, then replace IDs with returned values. The key selects Sandbox or Live. Each endpoint has cURL, Python and JavaScript examples generated from the same contract.

## Start underwriting

```bash
curl --request POST --fail-with-body --max-time 30 \
  "${AMLOK_API_BASE_URL}/v1/originations" \
  --header "Authorization: Bearer ${AMLOK_API_KEY}" \
  --header 'Accept: application/json' \
  --header 'Idempotency-Key: createOrigination-synthetic-0042' \
  --header 'Content-Type: application/json' \
  --data '{"borrower_id":"bor_synthetic","application":{"institution_reference":"LOS-2026-0042","requested_amount":{"amount":"50000.00","currency":"CAD"},"requested_term_months":12,"purpose":"Working capital","application_schema_id":"app_schema_synthetic","declared_data":{"annual_revenue":"600000.00"}},"lending_product_version_id":"lpv_synthetic","risk_policy_version_id":"rpv_synthetic","connection_ids":["con_synthetic"],"document_ids":[]}'
```

## Read the risk package

```bash
curl --request GET --fail-with-body --max-time 30 \
  "${AMLOK_API_BASE_URL}/v1/risk-packages/record_synthetic" \
  --header "Authorization: Bearer ${AMLOK_API_KEY}" \
  --header 'Accept: application/json'
```

## Inspect supporting evidence

```bash
curl --request GET --fail-with-body --max-time 30 \
  "${AMLOK_API_BASE_URL}/v1/evidence?evidence_set_id=es_synthetic" \
  --header "Authorization: Bearer ${AMLOK_API_KEY}" \
  --header 'Accept: application/json'
```

## Enroll a funded deal

```bash
curl --request POST --fail-with-body --max-time 30 \
  "${AMLOK_API_BASE_URL}/v1/monitors" \
  --header "Authorization: Bearer ${AMLOK_API_KEY}" \
  --header 'Accept: application/json' \
  --header 'Idempotency-Key: createMonitor-synthetic-0042' \
  --header 'Content-Type: application/json' \
  --data '{"borrower_id":"bor_synthetic","deal":{"institution_reference":"LOAN-0042","funded_amount":{"amount":"50000.00","currency":"CAD"},"outstanding_amount":{"amount":"50000.00","currency":"CAD"},"funded_at":"2026-11-05T12:00:00Z","maturity_date":"2027-11-06","repayment_frequency":"monthly","terms_document_ids":[]},"baseline":{"risk_package_id":"rp_synthetic"},"risk_policy_version_id":"rpv_synthetic","cadence_id":"cadence_synthetic","connection_ids":["con_synthetic"]}'
```

## Export an assessment

```bash
curl --request POST --fail-with-body --max-time 30 \
  "${AMLOK_API_BASE_URL}/v1/exports" \
  --header "Authorization: Bearer ${AMLOK_API_KEY}" \
  --header 'Accept: application/json' \
  --header 'Idempotency-Key: createExport-synthetic-0042' \
  --header 'Content-Type: application/json' \
  --data '{"kind":"risk_package","risk_package_id":"rp_synthetic","format":"json"}'
```

Use [Postman](/downloads/amlok-api.postman_collection.json) for all 67 operations and the [complete risk-package example](/downloads/risk-package-example.json) for result structure. Requests are not a claim of live backend execution.
