Issue a short-lived download URL for an authorized available file. Recheck source entitlement and borrower access; possession of a document ID alone grants nothing. All IDs and cursors must belong to the authorized workspace and environment. Required scope: evidence:read.

Examples use synthetic IDs. Replace them with values returned by your environment.
