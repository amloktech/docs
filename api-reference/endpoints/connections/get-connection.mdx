Inspect one borrower connection and its collection status. Use a Hub reauthorization session when borrower action is required; no provider credentials are returned. All IDs and cursors must belong to the authorized workspace and environment. Required scope: connections:read.

Examples use synthetic IDs. Replace them with values returned by your environment.
