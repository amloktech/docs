Inspect borrower-authorized integrations, connection status, ingestion readiness, freshness and coverage. The Hub performs authorization; this endpoint exposes its result without configuring integrations. All IDs and cursors must belong to the authorized workspace and environment. Required scope: connections:read.

Examples use synthetic IDs. Replace them with values returned by your environment.
