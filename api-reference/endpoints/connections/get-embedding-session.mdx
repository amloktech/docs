Inspect the borrower-specific execution of a Hub configured in the console. Session completion confirms connection setup, not ingestion readiness or underwriting completion. All IDs and cursors must belong to the authorized workspace and environment. Required scope: connections:read.

Examples use synthetic IDs. Replace them with values returned by your environment.
