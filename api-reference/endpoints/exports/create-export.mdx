Prepare a risk package, evidence set or billing report for download. Each kind requires its own source permissions in addition to export access. All IDs and cursors must belong to the authorized workspace and environment. Required scope: exports:write. Data exports require data:read and source authorization; risk-package exports require results:read; billing exports require billing:read and Owner authority; evidence exports require evidence:read and source entitlements. Permissions are checked at creation, retrieval and download. Risk-package JSON exports include every detailed financial attribute and input manifest. PDF is a human-readable report: it includes the assessment and financial-attribute summary, with an explicit notice that the detailed attribute and input-manifest arrays are available through JSON export or paged API sections.

Examples use synthetic IDs. Replace them with values returned by your environment.
