---
title: "Retrieve credit ledger entry"
openapi: "/openapi/amlok-v1.json GET /v1/billing/credit-ledger/{id}"
playground: simple
---

**Required scope:** `billing:read`

Read an immutable posted movement by ledger_entry_id from a usage or funding record. Reversals reference the original entry. Balance_after describes the full account ledger, even when a filtered list omits other movements. The selected snapshot must include the movement; otherwise return 404.

Required scope: billing:read. The API key is bound to exactly one workspace, institution and environment. There is no workspace override; this binding applies to every read and export.
