title: "Create billing report"
openapi: "/openapi/amlok-v1.json POST /v1/billing/reports"
playground: simple

**Required scope:** `billing:export`

Generate a read-only snapshot export asynchronously. This does not change credits or payment settings. Dates are UTC [from,to); from must precede to. Poll until ready. CSV cells that could execute spreadsheet formulas are escaped.

[Credit reporting](/api-reference/credit-reporting) · [Consumption reporting](/api-reference/consumption-reporting) · [Cancellation and refunds](/pricing/refunds-and-payouts)

Use an idempotency key when creating an export or download link. These actions do not add, spend, or move credits.
