---
title: "Create billing report download link"
openapi: "/openapi/amlok-v1.json POST /v1/billing/reports/{id}/download-link"
playground: simple
---

**Required scope:** `billing:export`

Only ready, unexpired reports return a short-lived authorized URL. Treat the link as a secret.

Use an idempotency key when creating an export or download link. These actions do not add, spend, or move credits.
