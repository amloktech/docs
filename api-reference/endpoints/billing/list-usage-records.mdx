---
title: "List usage records"
openapi: "/openapi/amlok-v1.json GET /v1/billing/usage"
playground: simple
---

**Required scope:** `billing:read`

Read immutable usage charges and correcting reversals. Usage records exist only for actual deductions or their corrections; unfinished work is represented by its processing resource, not a pending credit category. Order by selected time_basis then id. No customer endpoint creates charges. Cancellation stops all further deductions.

Required scope: billing:read. The API key is bound to exactly one workspace, institution and environment. There is no workspace override; this binding applies to every read and export.
