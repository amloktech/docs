---
title: "Create agreement cancellation"
openapi: "/openapi/amlok-v1.json POST /v1/agreement-cancellations"
playground: simple
---

**Required scope:** `billing:manage`

Request final agreement cancellation using the quoted agreement version and signed notice terms. Confirmation establishes the effective date. At that date, stop new usage and automatic top-ups; reconcile all incurred product usage and in-flight funding, then set refund_pending and return the entire remaining paid balance. The cancellation links its final statement, refund amount and refund records. No withdrawal request is needed to establish the refund obligation.
