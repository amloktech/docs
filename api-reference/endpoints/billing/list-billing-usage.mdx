Read what was charged, for which borrower and product, with historical rate, tier, workload and links to the wallet transaction and assessment. Signal combines a borrower across deals once per workspace/month. All IDs and cursors must belong to the authorized workspace and environment. Required scope: billing:read. Owner authority is required. Related reads can pin snapshot_id from billing summary to reconcile the same as-of state; expired snapshots return 410, never a silent refresh. Complexity is assessed by Amlok, not selected by HTTP volume. Usage records preserve the original tier, rate and agreement version. Funding commitments are available in billing summary pricing.commitment.

Examples use synthetic IDs. Replace them with values returned by your environment.
