---
title: "List billing reports"
openapi: "/openapi/amlok-v1.json GET /v1/billing/reports"
playground: simple
---

**Required scope:** `billing:export`

Read current export-job status, its frozen financial snapshot and expiry. Job status is current, while exported data stays bound to snapshot_id. Order by created_at then id.

Required scope: billing:export. The API key is bound to exactly one workspace, institution and environment. There is no workspace override; this binding applies to every read and export.
