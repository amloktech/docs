---
title: "Retrieve current billing snapshot"
openapi: "/openapi/amlok-v1.json GET /v1/billing/snapshot"
playground: simple
---

**Required scope:** `billing:read`

Read a consistent workspace billing snapshot. The snapshot freezes financial resource versions, rate cards, pending funding, holds, and the posted ledger high-water mark at as_of. Reuse its id as snapshot_id on financial reads and export requests. Later postings or corrections never change this snapshot. Snapshots are available until workspace deletion; export needed evidence before closure. Unknown or deleted snapshot IDs return 404. This read does not spend credits or change payment settings.
