---
title: "Retrieve billing statement"
openapi: "/openapi/amlok-v1.json GET /v1/billing/statements/{id}"
playground: simple
---

**Required scope:** `billing:read`

Statements reconcile posted ledger movements and carry their own frozen snapshot_id. Final revisions are immutable; later corrections create a linked revision. Return revisions in period-start, revision, id order. Date filters match overlapping statement periods. Use report_type statement to export the exact statement snapshot and period.

Required scope: billing:read. The API key is bound to exactly one workspace, institution and environment. There is no workspace override; this binding applies to every read and export.
