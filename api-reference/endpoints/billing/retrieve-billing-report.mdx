---
title: "Retrieve billing report"
openapi: "/openapi/amlok-v1.json GET /v1/billing/reports/{id}"
playground: simple
---

**Required scope:** `billing:export`

Read current export-job status, its frozen financial snapshot and expiry. Job status is current, while exported data stays bound to snapshot_id. Order by created_at then id.
