Retrieve an immutable Insights or Signal result with financial dimensions, policy evaluations, limitations and the frozen supporting evidence set. Recommendations do not replace the institution decision. All IDs and cursors must belong to the authorized workspace and environment. Required scope: results:read. Use view=summary for the section index, or view=section with section/cursor/limit for bounded detail. Invalid parameter combinations return 400 validation_error. Full or single-item responses above max_response_bytes return 413 response_too_large with an export source; no fields are silently omitted. Detailed financial attributes and their input manifests are available as paged sections. Attribute filters bind the cursor and total_items counts matching records. Invalid filter/section combinations return 400 validation_error. Historical packages may predate these optional sections. Use section=metrics to page individual metrics with their parent dimension key/status when a whole dimension is too large; begin with limit=1 and follow page.next_cursor. This derived view preserves every metric field and does not add a metrics field to stored RiskPackage objects or full exports.

Examples use synthetic IDs. Replace them with values returned by your environment.

## Operation name

`getRiskPackage`

The `X-Amlok-Operation-Id` response header identifies this endpoint. Request receipts apply to accepted POST commands.
