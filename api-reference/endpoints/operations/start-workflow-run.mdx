**Required scope:** `workflows:execute` · **Execution:** asynchronous.

No external action without scoped institutional authorization. Billable work requires available credits covering its cost; otherwise return 402 insufficient_credits before accepting work, with no debit. A separately requested full underwriting uses Insights. Signal change-driven reassessment is included in Signal and does not create an additional Insights charge.

[Data dictionary](/data-model/field-dictionary#workflow-run) · [Response conventions](/api-reference/response-format) · [Errors](/api-reference/errors)

Poll `GET /v1/workflow-runs/{id}` with the returned resource ID, or consume the relevant webhook. A successful submission does not mean the work completed.

**Lifecycle event:** `workflow.completed`. See [webhook delivery and verification](/api-reference/webhooks).
