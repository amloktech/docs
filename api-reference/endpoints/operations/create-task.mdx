**Required scope:** `operations:write` · **Execution:** synchronous.

Effectful tasks must enter approval state. Once account cancellation is submitted, processing and usage deductions stop immediately. Reject new operational commands with 409 invalid_state; pending work is cancelled and unused holds are released without another debit. Read-only reporting remains available until workspace deletion.
