Recover the accepted resource using the original operation and idempotency key after a timeout or expired response cache. Do not submit accepted work as a new command. All IDs and cursors must belong to the authorized workspace and environment. Required scope: reliability:read.

Examples use synthetic IDs. Replace them with values returned by your environment.
