Service status. All IDs and cursors must belong to the authorized workspace and environment. No API key is required.

Examples use synthetic IDs. Replace them with values returned by your environment.

## Operation name

`serviceStatus`

The `X-Amlok-Operation-Id` response header identifies this endpoint. Request receipts apply to accepted POST commands.
