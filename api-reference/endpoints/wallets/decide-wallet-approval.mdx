**Required scope:** `wallets:approve`

An independent authorized actor approves or rejects the exact movement version. The initiator cannot self-approve. Expired, changed or already decided requests fail. Execution rechecks balance, holds and destination. This authorizes refund delivery instructions only. Rejecting or expiring an instruction does not forfeit the balance or cancel the refund obligation; no approval can bypass the final-cancellation requirement.
