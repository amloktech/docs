title: "Cancel wallet refund"
openapi: "/openapi/amlok-v1.json POST /v1/wallet-refunds/{id}/cancel"
playground: simple
---

**Required scope:** `wallets:refund`

Stop only a cancellable delivery attempt before rail submission. This does not cancel the agreement cancellation or forgive the remaining refund obligation. Confirm no funds left before releasing reservations. Resolve delivery instructions and retry the same refund; never create a second refund for the same balance.

[Wallet lifecycle](/api-reference/wallets) · [Consumption reporting](/api-reference/consumption-reporting) · [Refunds and payouts](/pricing/refunds-and-payouts)

Use an idempotency key for every mutation. Money commands also require a durable, institution-scoped business reference. A successful submission is not confirmation of settlement.
