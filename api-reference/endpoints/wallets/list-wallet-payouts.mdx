**Required scope:** `wallets:read`

Track delivery of final-cancellation refunds only, including allocations to original funding sources or an approved verified same-owner fallback. This namespace is separate from provider payment /v1/payouts. A return restores the returned principal once to the closed or closing wallet, remains owed under the same cancellation, and cannot fund new services.
