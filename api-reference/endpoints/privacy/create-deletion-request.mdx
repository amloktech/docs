**Required scope:** `privacy:write` · **Execution:** asynchronous.

No deletion is performed merely by writing this API design.

Poll `GET /v1/deletion-requests/{id}` with the returned resource ID, or consume the relevant webhook. A successful submission does not mean the work completed.

**Lifecycle event:** `deletion.completed`. See [webhook delivery and verification](/api-reference/webhooks).
