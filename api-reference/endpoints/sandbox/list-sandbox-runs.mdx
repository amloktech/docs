---
title: "List Sandbox runs"
description: "List Sandbox runs."
openapi: "/openapi/amlok.json GET /v1/sandbox/runs"
---

Returns the newest runs first, bounded to limit. List entries omit steps and resources; retrieve a run to inspect its execution. Billing runs are visible only to Owners with billing:read. See [Sandbox scenarios](/api-reference/sandbox-journeys) for permissions, fixture coverage, expected results, delivery controls and limitations.

Examples use synthetic IDs. Replace them with values returned by your environment.
