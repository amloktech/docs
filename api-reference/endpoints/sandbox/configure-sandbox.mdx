---
title: "Choose empty or sample Sandbox"
description: "Choose empty or sample Sandbox."
openapi: "/openapi/amlok.json POST /v1/sandbox/setup"
---

Persist a workspace-wide initial choice. Samples queue six businesses and associated records. Empty preserves existing data and provides synthetic credits. The choice cannot erase data. Owners can load samples; Owners and Developers can choose empty. Concurrent setup requests return the existing choice. See [Sandbox scenarios](/api-reference/sandbox-journeys) for permissions, fixture coverage, expected results, delivery controls and limitations.

Examples use synthetic IDs. Replace them with values returned by your environment.
