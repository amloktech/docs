---
title: "Repeat a scenario with fresh records"
description: "Repeat a scenario with fresh records."
openapi: "/openapi/amlok.json POST /v1/sandbox/runs/{id}/repeat"
---

Reset the scenario by starting a fresh isolated run with the same version, fixture and settings. Preserves immutable history, billing and other developer records. The existing run is never rewritten or deleted. See [Sandbox scenarios](/api-reference/sandbox-journeys) for permissions, fixture coverage, expected results, delivery controls and limitations.

Examples use synthetic IDs. Replace them with values returned by your environment.
