title: "Get configuration"
description: "Discover the approved schemas, products, integration IDs, embedding versions and monitoring cadences available to this API key."
openapi: "/openapi/amlok.json GET /v1/configuration"
---

Discover the approved schemas, products, integration IDs, embedding versions and monitoring cadences available to this API key. All IDs and cursors must belong to the authorized workspace and environment. Required scope: configuration:read.

Examples use synthetic IDs. Replace them with values returned by your environment.
