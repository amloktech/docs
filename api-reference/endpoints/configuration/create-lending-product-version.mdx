openapi: "/openapi/amlok.json POST /v1/lending-product-versions"
---

Store an immutable version of a lending product, including eligibility, pricing and repayment terms. This is your lending catalog, not merchant inventory. All IDs and cursors must belong to the authorized workspace and environment. Required scope: configuration:write.

Examples use synthetic IDs. Replace them with values returned by your environment.
