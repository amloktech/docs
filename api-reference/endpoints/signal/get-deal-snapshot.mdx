---
title: "Get deal snapshot"
description: "Retrieve the exact lender input version used by a monitoring run or risk package, including its effective time and previous version."
openapi: "/openapi/amlok.json GET /v1/deal-snapshots/{id}"
---

Retrieve the exact lender input version used by a monitoring run or risk package, including its effective time and previous version. All IDs and cursors must belong to the authorized workspace and environment. Required scope: signal:read.

Examples use synthetic IDs. Replace them with values returned by your environment.
