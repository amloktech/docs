Inspect scheduled or change-driven monitoring evaluations, including per-integration freshness, coverage, failures and the resulting risk package. All IDs and cursors must belong to the authorized workspace and environment. Required scope: signal:read.

Examples use synthetic IDs. Replace them with values returned by your environment.
