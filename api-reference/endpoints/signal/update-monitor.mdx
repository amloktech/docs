---
title: "Update monitor"
description: "Change future monitoring configuration with the current ETag. Historical assessments, alerts, evidence and charges remain immutable. A stopped monitor cannot resume."
openapi: "/openapi/amlok.json PATCH /v1/monitors/{id}"
---

Change future monitoring configuration with the current ETag. Historical assessments, alerts, evidence and charges remain immutable. A stopped monitor cannot resume. All IDs and cursors must belong to the authorized workspace and environment. Required scope: signal:write.

Examples use synthetic IDs. Replace them with values returned by your environment.
