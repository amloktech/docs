Use these artifacts for the primary API 1.0.0 contract. Endpoint pages, request/response examples and Postman requests are generated from the same definitions.

- [OpenAPI 3.1 JSON](/openapi/amlok.json)
- [Postman collection: 65 operations](/downloads/amlok-api.postman_collection.json)
- [Operation index](/downloads/api-product-index.json)
- [Complete synthetic risk package](/downloads/risk-package-example.json)
- [Node.js webhook signature verifier](https://raw.githubusercontent.com/amloktech/docs/main/downloads/verify-webhook.mjs)
- [Python webhook signature verifier](https://raw.githubusercontent.com/amloktech/docs/main/downloads/verify_webhook.py)

The Postman collection defaults `base_url` to `https://api.amlok.io`, without `/v1`. Set `api_key` in a private environment. Use a Sandbox key for tests or a Live key for activated operations; do not change the hostname when switching between them. Keys and secrets are not included. The [OpenAPI specification](/overview/openapi-spec) is the source of truth. [SDK guidance](/overview/sdks) covers client generation.
