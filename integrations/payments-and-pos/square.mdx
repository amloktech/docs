OAuth + Orders, Payments, Refunds, and Payouts APIs; validate Canadian endpoint coverage.

## Access and approval

Self-serve API can launch with seller consent without formal partnership; Marketplace listing ETA ND. Review source.

**Documentation availability:** Public API/docs.

*ND means the source catalog does not disclose an approval estimate.*
