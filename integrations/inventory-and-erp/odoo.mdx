**Documentation availability:** Public external API/docs.

## Data refresh

**Provider update cadence:** On configured automation events or scheduled API reads.

Odoo automation rules can send webhook notifications to external services. Its external API supports authorized record reads; synchronization timing depends on the installed version and deployment configuration.

Odoo Online external API access requires an eligible Custom plan. The enabled modules, automation triggers, hosting, and scheduled jobs determine timing. A self-hosted or customized deployment can have different capabilities.

**AMLOK synchronization:** The enabled refresh mode and schedule are agreed for your connection. Provider timing describes upstream capability; allow for retrieval and processing before changes appear in AMLOK. See [data refresh and freshness](/integrations/data-refresh).

Provider references: [Odoo 19 automation rules](https://www.odoo.com/documentation/19.0/applications/studio/automated_actions.html), [Odoo 19 external API access](https://www.odoo.com/documentation/19.0/developer/reference/external_rpc_api.html).
