## Integration approach

OAuth REST API using the tenant's data-centre domain; reuse identity with Zoho Books where appropriate.

## Access and approval

Organization OAuth consent and app registration; Marketplace listing review separate; ETA ND.

**Documentation availability:** Public REST API/docs.

*ND means the source catalog does not disclose an approval estimate.*
