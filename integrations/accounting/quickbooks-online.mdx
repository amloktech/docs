OAuth 2.0 Accounting API and Reports; validate Canadian company/tax fields and production access.

## Access and approval

Production app assessment required; Marketplace listing is separate; dependable approval ETA ND. Review source.

**Documentation availability:** Public Accounting API/docs.

*ND means the source catalog does not disclose an approval estimate.*
