## Data refresh

**Provider update cadence:** On supported accounting events.

FreshBooks sends callbacks for subscribed events, including supported invoice, payment, expense, and client changes made through its application or API. These events can prompt an authorized resource read.

The webhook must be verified and have the required scopes. Supported events do not define a fixed refresh interval for every report or accounting resource; remaining reads follow the configured schedule.

**AMLOK synchronization:** The enabled refresh mode and schedule are agreed for your connection. Provider timing describes upstream capability; allow for retrieval and processing before changes appear in AMLOK. See [data refresh and freshness](/integrations/data-refresh).

Provider references: [FreshBooks webhook callbacks](https://www.freshbooks.com/api/webhooks).
