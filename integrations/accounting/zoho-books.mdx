## Integration approach

OAuth REST API; use the organization's correct data-centre domain and permissions.

## Access and approval

OAuth registration/organization consent; Marketplace listing review is separate; approval ETA ND. Review source.

**Documentation availability:** Public REST API/docs.

*ND means the source catalog does not disclose an approval estimate.*

## Data refresh

**Provider update cadence:** When configured workflow rules trigger.

Zoho Books supports outgoing webhooks associated with workflow rules. Matching events can notify the integration; authorized API reads retrieve supported records and reconcile changes.

The organization's enabled modules, workflow criteria, permissions, and API limits determine coverage and timing. Workflow notifications are not a universal change feed for every accounting record.

**AMLOK synchronization:** The enabled refresh mode and schedule are agreed for your connection. Provider timing describes upstream capability; allow for retrieval and processing before changes appear in AMLOK. See [data refresh and freshness](/integrations/data-refresh).

Provider references: [Zoho Books webhooks API](https://www.zoho.com/books/api/v3/webhooks/), [Zoho Books workflow automation](https://www.zoho.com/in/books/accounting-software/accounting-automation/).
