## Integration approach

OAuth 2.0 Accounting API/reports; some endpoints, including journals, have additional access gates.

## Access and approval

Published security-assessment guidance: about 5 working days to complete, then 5–10 working days for Xero review. Full certification/use-case approval ETA ND. Review source.

**Documentation availability:** Public Accounting API/docs.

*ND means the source catalog does not disclose an approval estimate.*

{/* BEGIN PROVIDER REFRESH */}
## Data refresh

**Provider update cadence:** On supported webhook events; API reads for other data.

Xero supports app-level webhook subscriptions for supported event categories across connected organizations. The applicable API supplies the resources needed after a notification or during a scheduled read.

Webhook coverage does not include every accounting resource. Retry or disabled subscriptions can delay delivery, and API access and limits govern reconciliation. Confirm the categories used by your connected organization.

**AMLOK synchronization:** The enabled refresh mode and schedule are agreed for your connection. Provider timing describes upstream capability; allow for retrieval and processing before changes appear in AMLOK. See [data refresh and freshness](/integrations/data-refresh).

Provider references: [Xero webhook overview](https://developer.xero.com/documentation/guides/webhooks/overview).
