## Data refresh

**Provider update cadence:** At the configured Web Connector interval or manual run.

QuickBooks Desktop Web Connector initiates scheduled or manual exchanges with the authorized company file. Its normal user interface supports update intervals of one minute or longer; the service can enforce a higher minimum.

The connector must be running and able to access the company file. A configured interval is the minimum time between connections, not a completion guarantee. Confirm compatibility with the installed Canadian edition.

**AMLOK synchronization:** The enabled refresh mode and schedule are agreed for your connection. Provider timing describes upstream capability; allow for retrieval and processing before changes appear in AMLOK. See [data refresh and freshness](/integrations/data-refresh).

Provider references: [Intuit Web Connector programmer guide](https://static.developer.intuit.com/resources/QBWC_proguide.pdf), [Intuit Web Connector overview](https://static.developer.intuit.com/output_html/qbdesktop/docs/get-started/get-started-with-quickbooks-web-connector.html).
