## Integration approach

Documented route uses JSON/Excel hot-folder imports through a Windows service, plus Salesforce integration. Confirm installed/cloud version; do not assume a general REST API.

## Access and approval

Confirm the required licence, service configuration and any custom connector with Margill. Approval ETA not published; the advertised trial duration is not approval time.

**Documentation availability:** Public API implementation PDF and product documentation.
