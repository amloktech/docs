## Integration approach

Use the Dataverse Web API for the lender's configured CRM tables and processes. Map custom lending entities and security roles; this connection does not automatically expose its LOS or core.

## Access and approval

Register the application in Microsoft Entra ID and configure delegated access or a server-to-server application identity. Lender permissions and licensing govern access; no fixed institution-approval ETA.

**Documentation availability:** Public Web API, OAuth and app-registration documentation.
