## Integration approach

REST APIs and webhooks connect loan records and workflow events. U.S.-oriented mortgage system; validate fit for the target lender and Canadian workflow before selection.

## Access and approval

ISV route requires partner API keys and lender-admin setup as a supported partner; keys are issued per partner/lender pair. Published approval ETA not found.

**Documentation availability:** Public Encompass Developer Connect guides and API catalogue.
