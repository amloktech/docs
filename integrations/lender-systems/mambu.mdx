## Integration approach

Tenant-specific banking APIs for clients, loan accounts and transactions. Match API version and permissions; streaming and other services can have separate access requirements.

## Access and approval

Tenant administrator grants scoped access. API consumers are documented as an Early Access feature requiring the customer-success team to enable. Approval ETA not published.

**Documentation availability:** Public API v2 reference and API-consumer/authentication documentation.
