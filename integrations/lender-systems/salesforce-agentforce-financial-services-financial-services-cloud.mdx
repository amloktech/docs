## Integration approach

Salesforce REST APIs connect CRM records; financial-services integration templates can use MuleSoft. CRM access alone does not provide access to the lender's core or LOS.

## Access and approval

Requires an authorized Salesforce org, API permissions and configured authentication. MuleSoft templates require a MuleSoft subscription and enablement. Private integration approval ETA is institution-specific; public listing is a separate route.

**Documentation availability:** Public REST and financial-services integration documentation.
