## Integration approach

REST/JSON LMS API with separate sandbox and production environments. Connect borrowers, loans, balances and events within the lender's configured access rights.

## Access and approval

Requires a LoanPro environment; an authorized account user creates tenant-scoped API tokens. No standard vendor approval ETA stated; new customer onboarding is separate.

**Documentation availability:** Public API reference, authentication and quickstart guides.
