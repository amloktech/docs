## Integration approach

Version-specific API with OAuth 2.0; XML Import supports borrowers, loans and transactions. Some operations use XML even when other endpoints support JSON.

## Access and approval

Requires deployment credentials, setup dependencies and appropriate licence. Active API connections can consume seats on per-user plans. Approval ETA not published.

**Documentation availability:** Public API guides and Swagger/OpenAPI documentation.
