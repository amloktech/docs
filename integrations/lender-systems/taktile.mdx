## Integration approach

Integrate with the institution's decision flows; obtain the applicable API schema, authentication and environment details from Taktile's gated documentation.

## Access and approval

Existing customers log in; others request documentation access. Confirm commercial/production onboarding with Taktile. No public access-approval or production-approval ETA found.

**Documentation availability:** Documentation/help centre exists but requires customer login or an access request; not an openly browsable reference.
