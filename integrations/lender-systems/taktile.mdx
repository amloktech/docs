## Integration approach

Integrate with the institution's decision flows; obtain the applicable API schema, authentication and environment details from Taktile's gated documentation.

## Access and approval

Existing customers log in; others request documentation access. Confirm commercial/production onboarding with Taktile. No public access-approval or production-approval ETA found.

**Documentation availability:** Documentation/help centre exists but requires customer login or an access request; not an openly browsable reference.

{/* BEGIN PROVIDER REFRESH */}
## Data refresh

**Provider update cadence:** Workflow-specific; agreed for the connected decision flow.

The refresh arrangement follows the institution's Taktile decision-flow integration and the freshness of its inputs. Confirm the supported invocation, result-delivery method, and repeat-execution schedule for the connected flow.

Detailed API documentation requires customer access. The public reference does not establish a universal polling or refresh interval. A new decision execution does not by itself guarantee that an upstream financial-data source has refreshed.

**AMLOK synchronization:** The enabled refresh mode and schedule are agreed for your connection. Provider timing describes upstream capability; allow for retrieval and processing before changes appear in AMLOK. See [data refresh and freshness](/integrations/data-refresh).

Provider references: [Taktile documentation access](https://taktile.com/docs-help-center), [Taktile customer documentation](https://docs.taktile.com/).
