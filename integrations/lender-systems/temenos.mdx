## Integration approach

Use the APIs for the lender's Temenos solution and deployment. Public developer sandbox is a model bank for evaluation and does not grant access to a lender's production environment.

## Access and approval

Published guidance: community registration usually takes about 30 minutes; sandbox keys last 30 days. These are not production approval times. Production commercial access must be arranged separately; ETA not stated.

**Documentation availability:** Public API portal and guides; sandbox requires community registration and an API key.
