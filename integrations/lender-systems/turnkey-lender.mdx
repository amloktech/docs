## Integration approach

API client and integration tools connect applications, customers, lending workflows and external systems. Confirm permissions and endpoints for the lender's deployed version.

## Access and approval

An authorized administrator can create API clients and keys in a provisioned system. Vendor/partner approval and production onboarding ETA not published.
