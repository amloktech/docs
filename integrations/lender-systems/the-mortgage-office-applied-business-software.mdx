## Integration approach

JSON web-service API for origination, servicing and mortgage pools. Documentation identifies a separate Canadian API environment.

## Access and approval

Production requests require an ABS-assigned token and company database. Arrange production access with ABS and the lender; approval ETA not published.

**Documentation availability:** Public API reference and sandbox instructions.
