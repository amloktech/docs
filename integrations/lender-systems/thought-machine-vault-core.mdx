## Integration approach

Connect the lender's Vault Core deployment through supported APIs and event streams. Confirm the account/product model and deployment-specific integration contract.

## Access and approval

Arrange technical documentation and environment access with the bank and Thought Machine. Production integration approval ETA not published in reviewed sources.

**Documentation availability:** Public architecture material confirms API connectivity; a public complete endpoint reference was not verified.
