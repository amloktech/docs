## Integration approach

Use supported Loan IQ APIs and the Nexus integration layer for loan booking and lifecycle events. Match the lender's release and licensed modules; do not assume every advertised module is deployed.

## Access and approval

Confirm customer licence, integration-module entitlement and lender-specific access/testing. No public production integration approval ETA found.

**Documentation availability:** Public API/SDK capability material; detailed production endpoint access should be confirmed with Finastra.
