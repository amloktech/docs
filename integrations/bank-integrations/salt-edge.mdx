## Integration approach

Account Information API and Connect flow for permissioned accounts and transactions. Use current API v6 and validate country, institution and partner/client route; do not infer Canadian coverage from global availability.

## Access and approval

Current docs: upgrade to Test is processed within 2 business days after required information. Submit implementation review at least 7 days before planned production release; this is lead-time guidance, not a Live-approval SLA. Live approval ETA not disclosed.

**Documentation availability:** Public API v6 reference and onboarding guides.
