## Integration approach

Flinks Connect plus API for permissioned bank accounts, balances and transaction history. Validate the particular Canadian institution, business account type, history and refresh access.

## Access and approval

Customer onboarding and production-instance credentials are required. Open-banking routes can also require data-provider activation. Production approval ETA not disclosed in reviewed sources.

**Documentation availability:** Public API documentation and Connect guides.

{/* BEGIN PROVIDER REFRESH */}
## Data refresh

**Provider update cadence:** Nightly for eligible connections; manual refresh when supported.

Flinks supports a daily scheduled refresh for eligible saved connections when scheduled refresh is enabled. Its published nightly job window is 04:00-08:00 UTC. An uncached authorization flow can request a manual refresh.

Eligibility depends on institution coverage, connection health, and applicable activity requirements. Some institutions do not support nightly refresh. MFA or credential changes can require the customer to reconnect; the nightly window is not a completion guarantee.

**AMLOK synchronization:** The enabled refresh mode and schedule are agreed for your connection. Provider timing describes upstream capability; allow for retrieval and processing before changes appear in AMLOK. See [data refresh and freshness](/integrations/data-refresh).

Provider references: [Flinks nightly refresh requirements and routine](https://help.flinks.com/support/solutions/articles/43000637682-nightly-refreshes).
