## Integration approach

FastLink plus Core APIs for accounts, transactions and holder information. Provider lookup includes US/Canada routing-number search; confirm actual Canadian bank and account-type coverage for the contracted datasets.

## Access and approval

Sandbox and production use different credentials and environments; production setup and contracted datasets require Yodlee coordination. Numeric approval ETA not disclosed in reviewed sources.

**Documentation availability:** Public Core API reference and FastLink integration documentation.
