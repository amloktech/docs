## Integration approach

Teller Connect plus APIs for accounts, balances, transactions and identity. Use mutual TLS for live-data API access. Published institution examples are US banks; Canadian-bank coverage is not established here.

## Access and approval

Production requires KYB verification, company/product information, beneficial-owner information and business documentation. Numeric approval ETA not disclosed. Development allows limited real-data testing and is separate from production approval.

**Documentation availability:** Public API reference, SDK guides and environment documentation.
