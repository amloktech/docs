## Integration approach

Financial Connections sessions plus APIs for balances, ownership and transactions. Published availability is for US bank accounts and eligible business countries; Canada is absent from the reviewed business-country list. Confirm eligibility before committing to this route.

## Access and approval

Requires an eligible Stripe business and enabled Financial Connections data permissions. Dedicated integration approval ETA not disclosed in reviewed docs; sandbox/testing does not establish Canadian eligibility or commercial access.

**Documentation availability:** Public API reference and Financial Connections guides.

## Data refresh

**Provider update cadence:** Daily subscribed transaction refresh; eligible on-demand requests.

Stripe Financial Connections refreshes transactions daily while an eligible active account is subscribed. A completion event reports the refresh result, after which transactions can be retrieved.

On-demand transaction refreshes must respect `transaction_refresh.next_refresh_available_at`. Inactive accounts cannot refresh. This daily cadence applies to subscribed transactions; balance and ownership are separate refresh features.

**AMLOK synchronization:** The enabled refresh mode and schedule are agreed for your connection. Provider timing describes upstream capability; allow for retrieval and processing before changes appear in AMLOK. See [data refresh and freshness](/integrations/data-refresh).

Provider references: [Stripe transaction refreshes](https://docs.stripe.com/financial-connections/transactions), [Stripe account refresh features](https://docs.stripe.com/api/financial_connections/accounts/refresh).
