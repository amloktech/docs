## Integration approach

Start an IBV session through the API, use Inverite's bank-selection flow, then receive account and transaction results through API/webhook. Canadian institutions are supported; history is up to 365 days depending on the bank.

## Access and approval

Merchant onboarding and API access must be arranged with Inverite. Numeric approval ETA not disclosed in reviewed sources; customer verification speed is not integration approval time.

**Documentation availability:** API workflow is public; official API Docs entry point is linked. Confirm access to the complete endpoint reference and credentials with Inverite.
