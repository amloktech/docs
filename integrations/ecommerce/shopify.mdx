## Integration approach

Admin GraphQL + authorized scopes/webhooks; older orders and protected customer data can require additional approval.

## Access and approval

Public app review required; numeric ETA ND; extra scopes can add review. Review source.

**Documentation availability:** Public API/docs.

*ND means the source catalog does not disclose an approval estimate.*

## Data refresh

**Provider update cadence:** Near-real-time notifications for subscribed topics.

Shopify provides near-real-time webhooks for subscribed topics such as orders, refunds, and inventory changes. Its APIs support follow-up retrieval and periodic reconciliation.

Shopify does not guarantee webhook delivery or ordering. Reconciliation is needed for missed events; available topics, protected data access, and API throttling depend on the app and shop.

**AMLOK synchronization:** The enabled refresh mode and schedule are agreed for your connection. Provider timing describes upstream capability; allow for retrieval and processing before changes appear in AMLOK. See [data refresh and freshness](/integrations/data-refresh).

Provider references: [Shopify webhooks and reconciliation](https://shopify.dev/docs/apps/build/webhooks).
