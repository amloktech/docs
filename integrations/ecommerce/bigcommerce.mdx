## Integration approach

OAuth/store API authorization; use administrative order APIs for history.

## Access and approval

Marketplace review required for distributed app; ETA ND. Store API credentials are a separate route. Review source.

**Documentation availability:** Public API/docs.

*ND means the source catalog does not disclose an approval estimate.*
