## Report a problem

Email [privacy@amlok.io](mailto:privacy@amlok.io) with the affected service, a short description, and the time the problem began. Use your agreed support channel for customer-specific issues.

The [operational status report](https://app.amlok.io/status) is maintained manually when known incidents occur. The summary above records the report when last reviewed. Check the source for subsequent updates; it is not an automated health probe or an uptime measurement.

## Service scope

These components cover **app.amlok.io** and the connected services named in its status report. Application API routes refer to that web application's endpoints. Enterprise API, Insights, and Signal availability and service commitments follow the applicable deployment and agreement.

For security incidents, see [incident response](/security/incident-response). For integration availability by market, use [catalog status](/integrations/status).
