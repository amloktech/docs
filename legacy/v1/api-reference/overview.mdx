This is the legacy 192-operation API contract. New documentation uses the [simplified API v2](/api-reference/overview).

<Warning>This archive describes v1 payloads and client responsibilities. Do not use it to build v2 requests.</Warning>

Use the [legacy quickstart](/legacy/v1/api-reference/quickstart), [workflow guide](/legacy/v1/api-reference/workflows), [OpenAPI specification](/openapi/amlok-v1.json) and [legacy endpoint index](/legacy/v1/index) when maintaining an existing v1 integration. The [migration map](/api-reference/product-api-migration) maps each operation to its replacement.

Documentation publication does not retire a running v1 environment. Coordinate environment enablement, identity mapping and cutover before migrating existing workloads.
