Research package 0.2 contains an original-source inventory, acquisition hashes, a record-level observation index, source-analysis outputs and a completed financial-document retrieval experiment. The package separates acquired records from documented access routes and measured results from planned model comparisons.

[Download the public-record research bundle](/downloads/research/amlok-public-records-0.2.zip). It includes the methods, derived artifacts and an integrity manifest. Original third-party reports and borrower-row extracts remain at their cited sources rather than being redistributed in the bundle.

The observation index comprises 1,014 parser-identified Québec interventions, 30 EDC disclosure rows, two issuer announcements and one aggregate facility-position table. These are source observations, not 1,047 adjudicated closed loans. The index retains company-text hashes for linkage reproducibility without republishing the company lists. A hash match is not independent legal-entity verification.

## Executed workflow

1. Retrieve explicitly listed public URLs through bounded requests. Record unsuccessful retrievals and distinguish complete files from byte prefixes.
2. Parse source tables and dictionaries. Preserve their units, repeated-language presentations and record types.
3. Render selected original PDF pages to inspect values the text layer may omit.
4. Build stable record IDs from the acquired source hash and explicit location. Record field availability and unresolved linkage.
5. Rank real FinQA evidence using two fixed lexical methods; score only after predictions exist.
6. Recompute metrics from saved item-level outputs and verify source, script and prediction hashes.

The source review includes selected manual visual checks, not independent double annotation of the full corpus. No paid registry searches, authenticated borrower-data downloads, hosted-model calls or production training jobs were executed.

## Run locally

Use Python 3.12 in an isolated environment from the documentation repository or extracted bundle:

```bash
python3 -m venv /tmp/amlok-public-research
/tmp/amlok-public-research/bin/python -m pip install -r scripts/research/requirements-public.txt
/tmp/amlok-public-research/bin/python scripts/research/acquire_public_audit.py
/tmp/amlok-public-research/bin/python scripts/research/analyze_public_sources.py
/tmp/amlok-public-research/bin/python scripts/research/build_source_register.py
/tmp/amlok-public-research/bin/python scripts/research/benchmark_public_evidence.py
/tmp/amlok-public-research/bin/python scripts/research/test_public_research.py
```

Acquisition writes original files to `artifacts/research-review/public-records`. Derived public outputs go to `downloads/research/public-records`. Downloading a source requires respecting its current terms; the acquisition script is not a grant of commercial training or redistribution rights. FinanceBench is inspected for source feasibility and is excluded from scoring/training.

The acquisition step skips successful snapshots already present. Reproduce this release with files matching the published hashes. If upstream content changes, preserve the new version separately and treat the run as a new dataset snapshot. If a source is unavailable, retain that status; do not replace it with invented rows. The SBA request deliberately captures only a bounded byte prefix ending on a complete row.

## Benchmark integrity

The FinQA ranking function uses only source text/table fields and the question. It excludes answers, programs, existing retrieved evidence and model-input annotations. Gold evidence IDs enter scoring after ranking. No supervised fitting or test-label tuning is performed.

The evaluation uses all 1,147 test questions. Table rows include their column headings. Recall is averaged per question; complete-evidence rate requires every annotated supporting item. Confidence intervals resample source filenames in paired comparisons and retain all questions in each selected cluster. They do not represent variation across independent institutions.

The checks verify source digests, record-index uniqueness and locators, count denominators, saved metrics, deterministic prediction reproduction, and exclusion of reference-answer fields from ranking. These checks establish artifact consistency, not a trained model's suitability for lending.

## Extending the corpus and experiments

Keep source snapshots immutable. Add retrieval history, licence/permission decisions, schema changes, extraction versions, correction records and adjudication logs. Publish the population flow from fetched documents to parsed observations, resolved facilities, eligible outcomes and final evaluation examples.

For a trained-model run, add checkpoint hashes, approved training purposes, split manifests, seeds, optimization settings, compute, failures and frozen predictions. For a frontier run, add exact API model identifiers, prompt/tool versions, raw responses and cost/latency logs under the [comparison protocol](/research/frontier-benchmark). Never fill an unrun result cell with an expected score.

Prior research artifacts remain versioned separately. They are not pooled with this public-record dataset, its denominators or its performance claims.
