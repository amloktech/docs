Generate a server-side client from the [current OpenAPI 3.1 contract](/openapi/amlok.json), or use the cURL, Python and JavaScript examples on each endpoint. The current contract contains 65 operations with typed request and response models.

Use `https://api.amlok.io` as the API origin. The OpenAPI server excludes `/v1` because each operation path includes it. A Sandbox key and a Live key use the same origin. See [URLs and environments](/api-reference/environments). Keep keys server-side, configure timeouts, reject cross-origin redirects and preserve idempotency keys during retries. Generated client types do not replace server authorization or JSON Schema conditional validation.

## Client generation

Generate your language's client from this OpenAPI file. The download contains the complete contract, including normalized evidence variants. Use the endpoint examples and Postman collection to check generated requests in your Sandbox. JSON Schema conditionals and source entitlements remain authoritative when a generator cannot express them as language types.

No packaged SDK is currently distributed. All published client examples and downloads use this same contract.
